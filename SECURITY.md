# Security

CleanMac moves files on your Mac, so safety bugs matter more than any other kind.

If you find a way to make CleanMac move something it should not (a path outside its allowed folders, an Apple system file, personal documents without your choice), please **do not open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/tastanmert/CleanMac/security/advisories/new).

Please include the macOS version, the CleanMac version and the exact path involved. You will get an answer within a few days.
